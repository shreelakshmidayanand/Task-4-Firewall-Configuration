# Task 4 - Setup and Use a Firewall on Windows

## Objective

Configure and test basic firewall rules to allow or block traffic using Windows Defender Firewall.

## Tool Used

* Windows Defender Firewall with Advanced Security

## Steps Performed

1. Opened Windows Defender Firewall with Advanced Security.
2. Viewed existing inbound firewall rules.
3. Created a new inbound rule.
4. Configured the rule to block TCP Port 23 (Telnet).
5. Applied the rule to Domain, Private, and Public profiles.
6. Verified the rule configuration.
7. Reviewed protocol and port settings.
8. Deleted the rule to restore the original firewall configuration.

Successfully configured, verified, and removed a firewall rule, gaining practical experience in firewall management and network traffic filtering.
